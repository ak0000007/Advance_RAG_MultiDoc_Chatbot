Senior Engineering Interview Cheatsheet (Top 10 Talking Points)

1. Why Hybrid Search (Dense + Sparse) with RRF? Dense vectors capture conceptual semantics but fail on numbers and codes ("$250 cap", "BK-001"). BM25 catches exact lexical tokens. Reciprocal Rank Fusion (RRF with k=60) merges both using rank positions without needing arbitrary score scaling.
2. Why Two-Stage Retrieval with Cross-Encoders? Bi-Encoders independently embed query and doc into vectors, allowing fast vector search (O(1) cosine). Cross-Encoders concatenate query and doc into Transformer layers, computing full token-to-token cross-attention for high precision. Two-stage searches top-20 with Bi-Encoder, then reranks down to top-5 with Cross-Encoder.
3. How is Multi-Tenant Isolation Enforced in Vector DBs? Pre-filtering rather than post-filtering. Every chunk is stamped with tenant_id during ingestion. The API extracts tenant_id from authenticated tokens and passes it into RunnableConfig, which enforces mandatory Qdrant payload filters and BM25 inverted index constraints.
4. How Does the Human-in-the-Loop (HITL) Gate Work? Mutating tools never execute DML directly; they return a proposed payload. LangGraph routes this to human_approval which fires interrupt(), serializing the state to PostgreSQL. The user reviews the payload in the UI and calls /chat/resume with Command(resume=decision) to execute the change.
5. How Do You Prevent Runaway LLM Loops and Mass Updates? Three-tier write guards: single_record_guard checks 15/18 alphanumeric SFID regex; bulk_intent_guard uses word-boundary regex \b(all|every|bulk)\b to block mass actions; session_write_cap caps total approved writes to 5 per conversation.
6. Why is Constant-Time Comparison (secrets.compare_digest) Necessary? Standard string equality (token == secret) aborts at the first unequal byte, leaking key characters via microsecond timing differences. secrets.compare_digest always evaluates all bytes in constant time.
7. What is the Fail-Safe Grader Pattern? Silent exception swallowing is an anti-pattern. If the LLM grader crashes on timeout or rate limit, the system logs full diagnostics with logger.error(..., exc_info=True) and tags context with [UNVERIFIED RETRIEVAL] so downstream components and users know the data was unverified.
8. Why Use Idempotent Deterministic Chunk IDs (UUIDv5)? Random UUIDs cause duplicate vectors upon re-indexing. RFC 4122 UUIDv5 hashes {tenant_id}:{source}:{chunk_idx}:{content_hash}, guaranteeing that re-ingesting documents results in clean, idempotent upserts in Qdrant and BM25.
9. How Do You Prevent PyTorch Event Loop Blocking in FastAPI? Inference calls like CrossEncoder.predict() are CPU/GPU-bound synchronous functions that block FastAPI's single-threaded event loop. We wrap them in await asyncio.to_thread(model.predict, pairs), executing them in thread worker pools.
10. How Does the Evaluation Benchmark Avoid Chunk ID Churn? Our evaluation harness in evals/rag/metrics.py evaluates relevance using normalized source file names and content substring presence rather than brittle chunk IDs. This allows engineers to tune chunk size or overlap without breaking the evaluation dataset.
